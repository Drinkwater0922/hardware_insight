# 视频精彩瞬间提取 - 交互设计规范

## 文档信息
- **版本**: v1.0
- **创建日期**: 2025-12-05
- **适用平台**: iOS 15+
- **设计工具**: Figma / Sketch

---

## 1. 设计原则

### 1.1 核心原则

#### 1.1.1 智能引导，减少决策
- 系统自动完成复杂操作，用户只需确认
- 在关键节点提供明确的下一步建议
- 避免让用户面对过多选择

#### 1.1.2 即时反馈，状态透明
- 每个操作都有立即的视觉反馈
- 长时间操作显示明确的进度指示
- 后台任务通过灵动岛保持可见性

#### 1.1.3 非阻塞式体验
- 支持后台处理，不阻塞其他操作
- 任务完成后通过通知提醒用户
- 用户可随时查看任务进度

#### 1.1.4 优雅的错误处理
- 错误提示清晰易懂，提供解决方案
- 自动重试机制，减少用户干预
- 降级方案保证基本功能可用

## 2. 交互流程设计

### 2.1 主流程交互

#### 场景1: 视频拍摄
```
用户操作                    系统反馈                     状态变化
───────────────────────────────────────────────────────────────
打开相机                → 显示取景框                → 准备就绪
                         状态栏显示时间/电量

点击快门按钮            → 按钮缩放动画(95%)        → 开始录制
                         按钮变为红色方形
                         显示"拍摄中"文字

再次点击快门            → 按钮缩放动画              → 停止录制
                         按钮恢复圆形
                         显示"拍摄完成"文字

自动返回桌面(2秒)       → 页面转场动画              → 进入处理
                         顶部显示通知
```

**交互细节**:
- **快门按钮点击反馈**: 触觉反馈(轻触) + 视觉缩放
- **状态文字**: 居中显示，红色，淡入/淡出动画(300ms)
- **自动返回**: 拍摄完成后2秒自动返回，用户也可手动返回

#### 场景2: Live图生成与查看
```
用户操作                    系统反馈                     状态变化
───────────────────────────────────────────────────────────────
返回桌面                → 顶部通知:"正在生成..."    → 后台处理
                         内容网格显示处理卡片
                         Spinner旋转动画

等待处理(20-30秒)       → 进度通知实时更新          → 处理中
                         "80%" → "90%" → "100%"

生成完成                → 通知:"精彩瞬间已准备就绪" → 已完成
                         弹出"高光Live提取完成"卡片
                         显示第一张预览图

点击"查看"按钮         → 卡片淡出(200ms)           → 进入相册
                         页面从下向上推入(400ms)

浏览Live相册            → 显示6个Live图网格         → 展示内容
                         每项悬停放大效果

点击任意Live图          → 全屏展开动画(300ms)       → 查看详情
                         显示日期时间
                         显示操作按钮

停留3秒                 → 弹出对话框                → 智能提示
                         "要将这些Live图合成
                          高光视频吗?"
```

**交互细节**:
- **通知显示**: 从顶部滑入(300ms) + 淡入效果
- **通知持续时间**: 3-5秒后自动消失，除非用户交互
- **卡片点击**: 按下时缩放至98%，松开恢复 + 触觉反馈
- **网格浏览**: 支持滚动，惯性滚动效果
- **3秒延迟**: 避免打扰用户，给予浏览时间

#### 场景3: 视频合成处理
```
用户操作                    系统反馈                     状态变化
───────────────────────────────────────────────────────────────
点击"OK"按钮           → 对话框向下滑出(300ms)     → 开始合成
                         页面转场至Stepfun界面

查看处理进度            → 显示3个处理步骤           → 实时更新
                         步骤1: ✓ 已完成(绿色)
                         步骤2: ✓ 已完成(绿色)
                         步骤3: ○ 进行中(蓝色Spinner)

点击返回/Home键         → 最小化至灵动岛            → 后台运行
                         灵动岛展开显示任务状态
                         底部Toast:"任务将在后台继续"

点击灵动岛              → 展开显示任务详情          → 查看状态
                         "合成高光集锦视频"
                         "剩余约15秒"

任务完成                → 灵动岛闪烁提示            → 已完成
                         通知:"视频已生成完成"
                         触觉反馈(成功)
```

**交互细节**:
- **步骤指示器**: 圆形，32px，带动画过渡
  - 待处理: 灰色背景 + 灰色图标
  - 进行中: 蓝色背景 + 白色Spinner(旋转动画)
  - 已完成: 绿色背景 + 白色勾选(弹性出现)
- **进度时间**: 每秒更新，格式"00:00"
- **返回行为**: 不中断任务，平滑最小化

#### 场景4: 多任务管理
```
用户操作                    系统反馈                     状态变化
───────────────────────────────────────────────────────────────
有多个任务运行          → 灵动岛自动展开            → 显示计数
                         "正在处理 2 个任务"
                         渐变展开动画(400ms)

点击灵动岛              → 页面推入任务列表          → 查看列表
                         显示所有进行中任务

选择某个任务            → 进入任务详情页            → 查看详情
                         显示该任务的完整信息

任务失败                → 卡片显示错误状态          → 失败提示
                         红色错误图标
                         "处理失败·点击重试"

点击重试                → 重新加入队列              → 重新处理
                         状态恢复为"处理中"
```

**交互细节**:
- **灵动岛展开**: Cubic-bezier(0.4, 0, 0.2, 1)曲线，400ms
- **任务卡片**: 白色背景，圆角16px，轻微阴影
- **进度条**: 高度4px，蓝色，平滑过渡(300ms)
- **左滑删除**: 卡片左滑显示红色删除按钮，再次左滑删除

## 3. 手势交互规范

### 3.1 基础手势

#### 3.1.1 点击 (Tap)
**适用场景**: 按钮、卡片、列表项

**交互效果**:
- 按下: 缩放至95-98%，透明度降至90%
- 持续时间: 150ms
- 松开: 恢复原状(150ms) + 执行操作
- 触觉反馈: 轻触(Light Impact)

**示例**:
```
按钮点击:
  按下   → Scale(0.95) + Opacity(0.9) + Haptic
  松开   → Scale(1.0) + Opacity(1.0) + 执行操作
```

#### 3.1.2 长按 (Long Press)
**适用场景**: Live图播放、更多操作菜单

**交互效果**:
- 识别时间: 500ms
- 按下反馈: 缩放至98%
- 识别成功: 触觉反馈(Medium Impact) + 执行操作
- 持续反馈: 根据具体功能设计

**示例**:
```
Live图长按:
  按下500ms → Haptic + 开始播放动画
  持续按住  → 循环播放
  松开      → 恢复静态图
```

#### 3.1.3 滑动 (Swipe)
**适用场景**: 照片切换、任务卡片删除

**交互效果**:
- 识别距离: 50px
- 滑动速度: 跟随手指，阻尼系数0.8
- 完成阈值: 屏幕宽度的30%或速度>500px/s
- 回弹动画: Spring(damping: 0.8, duration: 0.3s)

**示例**:
```
照片左右滑动切换:
  右滑 → 上一张 (从左侧滑入)
  左滑 → 下一张 (从右侧滑入)

任务卡片左滑删除:
  左滑<30% → 回弹
  左滑≥30% → 显示删除按钮
  继续左滑 → 删除并淡出
```

#### 3.1.4 捏合 (Pinch)
**适用场景**: 照片缩放

**交互效果**:
- 缩放范围: 1.0x - 3.0x
- 缩放中心: 两指中点
- 边界处理: 阻尼效果，超出范围时阻力增大
- 松开后: 回弹至最近的有效缩放级别

### 3.2 高级交互

#### 3.2.1 下拉刷新
**适用场景**: 任务列表、Live相册

**交互流程**:
```
1. 下拉 (0-60px)      → 显示刷新指示器，跟随手指
2. 下拉 (>60px)       → 指示器变为"释放刷新"状态
3. 松开               → 指示器旋转动画 + 触发刷新
4. 刷新完成           → 指示器淡出(200ms)
```

**视觉反馈**:
- 指示器: 圆形Spinner，灰色 → 蓝色
- 文字提示: "下拉刷新" → "释放刷新" → "刷新中..."

#### 3.2.2 侧边缘滑动返回
**适用场景**: 所有支持返回的页面

**交互流程**:
```
1. 从左边缘滑动 (0-30px内开始)
2. 当前页面跟随手指向右移动
3. 上一页面从左侧逐渐显示
4. 滑动>50%或速度>600px/s → 完成返回
5. 否则 → 回弹到当前页面
```

**视觉效果**:
- 当前页面: 阴影加深，随滑动位置变化
- 上一页面: 从左侧-30%位置开始显示

## 4. 动画设计规范

### 4.1 动画时长标准

| 动画类型 | 时长 | 适用场景 |
|---------|------|---------|
| 微交互 | 150-200ms | 按钮点击、状态切换 |
| 标准过渡 | 300ms | 元素显示/隐藏、颜色变化 |
| 页面转场 | 400ms | 页面推入/弹出 |
| 复杂动画 | 600ms | 多步骤动画、特殊效果 |

### 4.2 缓动函数

| 函数类型 | 参数 | 适用场景 |
|---------|------|---------|
| Ease-out | cubic-bezier(0, 0, 0.2, 1) | 进入动画、显示元素 |
| Ease-in | cubic-bezier(0.4, 0, 1, 1) | 退出动画、隐藏元素 |
| Ease-in-out | cubic-bezier(0.4, 0, 0.2, 1) | 状态切换、位置移动 |
| Spring | damping: 0.8, mass: 1 | 回弹效果、弹性动画 |

### 4.3 动画示例

#### 4.3.1 通知进入/退出
```css
/* 进入 */
@keyframes notification-enter {
  from {
    transform: translateY(-100%);
    opacity: 0;
  }
  to {
    transform: translateY(0);
    opacity: 1;
  }
}
animation: notification-enter 300ms ease-out;

/* 退出 */
@keyframes notification-exit {
  from {
    transform: translateY(0);
    opacity: 1;
  }
  to {
    transform: translateY(-100%);
    opacity: 0;
  }
}
animation: notification-exit 300ms ease-in;
```

#### 4.3.2 对话框弹出/消失
```css
/* 弹出 */
@keyframes dialog-enter {
  from {
    transform: translateY(100%) scale(0.9);
    opacity: 0;
  }
  to {
    transform: translateY(0) scale(1);
    opacity: 1;
  }
}
animation: dialog-enter 400ms cubic-bezier(0.4, 0, 0.2, 1);

/* 消失 */
@keyframes dialog-exit {
  from {
    transform: translateY(0) scale(1);
    opacity: 1;
  }
  to {
    transform: translateY(100%) scale(0.9);
    opacity: 0;
  }
}
animation: dialog-exit 300ms cubic-bezier(0.4, 0, 1, 1);
```

#### 4.3.3 灵动岛展开/收起
```css
/* 展开 */
@keyframes island-expand {
  from {
    width: 126px;
    height: 37px;
    border-radius: 24px;
  }
  to {
    width: 350px;
    height: 80px;
    border-radius: 40px;
  }
}
animation: island-expand 400ms cubic-bezier(0.4, 0, 0.2, 1);

/* 收起 */
@keyframes island-collapse {
  from {
    width: 350px;
    height: 80px;
    border-radius: 40px;
  }
  to {
    width: 126px;
    height: 37px;
    border-radius: 24px;
  }
}
animation: island-collapse 400ms cubic-bezier(0.4, 0, 0.2, 1);
```

#### 4.3.4 Spinner旋转
```css
@keyframes spin {
  from {
    transform: rotate(0deg);
  }
  to {
    transform: rotate(360deg);
  }
}
animation: spin 1s linear infinite;
```

#### 4.3.5 进度条增长
```css
@keyframes progress-grow {
  from {
    width: 0%;
  }
  to {
    width: var(--progress-value);
  }
}
animation: progress-grow 300ms ease-out;
transition: width 300ms ease-out; /* 用于动态变化 */
```

## 5. 状态反馈设计

### 5.1 加载状态

#### 5.1.1 Spinner加载
**使用场景**: 内容加载中、处理中

**规格**:
- 尺寸: 40x40px (大) / 20x20px (小)
- 颜色: 系统蓝色 (#007AFF)
- 动画: 旋转，1秒一圈
- 背景: 可选灰色圆形底

**示例**:
```
卡片加载中:
  ┌──────────────┐
  │              │
  │      ⟳      │  ← Spinner (40x40px)
  │  加载中...   │  ← 文字提示 (13px)
  │              │
  └──────────────┘
```

#### 5.1.2 进度条
**使用场景**: 上传、下载、处理进度

**规格**:
- 高度: 4px
- 背景色: 浅灰色 (#E5E5EA)
- 填充色: 系统蓝色 (#007AFF)
- 圆角: 2px
- 过渡: 300ms ease-out

**示例**:
```
任务进度:
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

#### 5.1.3 骨架屏
**使用场景**: 内容首次加载

**规格**:
- 背景色: 浅灰色 (#F0F0F0)
- 动画: 从左到右扫光效果
- 形状: 模拟实际内容布局
- 持续时间: 2s infinite

### 5.2 成功/失败状态

#### 5.2.1 成功提示
**视觉元素**:
- 图标: ✓ 绿色圆形勾选
- 颜色: #34C759
- 动画: 从小到大弹出(300ms)
- 触觉: 成功反馈(Notification Success)

**示例**:
```
步骤完成:
  ┌────┐
  │ ✓ │  ← 绿色圆形(32px)
  └────┘
```

**视觉元素**:
- 图标: ✕ 红色圆形叉号
- 颜色: #FF3B30
- 动画: 摇晃动画(400ms)
- 触觉: 错误反馈(Notification Error)

**示例**:
```
处理失败:
  ┌────┐
  │ ✕ │  ← 红色圆形(32px)
  └────┘
  处理失败  ← 文字(14px)

```

#### 5.3.1 无内容

- 插图: 简单的灰色图标(80x80px)

## 6. 触觉反馈规范

### 6.1 触觉类型

| 触觉类型 | 强度 | 适用场景 |
|---------|------|---------|
| Light Impact | 轻 | 按钮点击、选择 |
| Medium Impact | 中 | 长按识别、重要操作 |
| Heavy Impact | 重 | 错误、警告 |
| Notification Success | 成功 | 任务完成、操作成功 |
| Notification Warning | 警告 | 需要注意的提示 |
| Notification Error | 错误 | 操作失败、错误 |

### 6.2 使用场景

```
用户操作                  触觉反馈类型
─────────────────────────────────────
点击按钮                  Light Impact
点击卡片                  Light Impact
长按Live图                Medium Impact
滑动切换照片              Light Impact (切换时)
下拉刷新                  Light Impact (释放时)
拍摄完成                  Notification Success
Live图生成完成            Notification Success
视频合成完成              Notification Success
上传失败                  Notification Error
处理失败                  Notification Error
空间不足                  Notification Warning
```

## 7. 页面转场规范

### 7.1 推入/推出 (Push/Pop)
**适用场景**: 层级导航（相册 → 照片详情）

**动画效果**:
```
推入:
  当前页面: 向左移出(至-30%位置) + 轻微缩小(0.95)
  新页面: 从右侧滑入(100% → 0)
  时长: 400ms
  曲线: cubic-bezier(0.4, 0, 0.2, 1)

推出:
  当前页面: 向右滑出(0 → 100%)
  上一页面: 从左侧滑入(-30% → 0) + 恢复原大小(0.95 → 1)
  时长: 400ms
  曲线: cubic-bezier(0.4, 0, 0.2, 1)
```

### 7.2 弹出/消失 (Present/Dismiss)
**适用场景**: 模态页面（Stepfun处理页、任务列表）

**动画效果**:
```
弹出:
  遮罩: 淡入(0 → 0.4透明度)
  页面: 从底部向上滑入(100% → 0) + 轻微缩放(0.95 → 1)
  时长: 400ms
  曲线: cubic-bezier(0.4, 0, 0.2, 1)

消失:
  遮罩: 淡出(0.4 → 0透明度)
  页面: 向底部滑出(0 → 100%)
  时长: 300ms
  曲线: cubic-bezier(0.4, 0, 1, 1)
```

### 7.3 渐变 (Fade)
**适用场景**: 小元素显示/隐藏（通知、Toast）

**动画效果**:
```
淡入:
  透明度: 0 → 1
  时长: 200ms
  曲线: ease-out

淡出:
  透明度: 1 → 0
  时长: 200ms
  曲线: ease-in
```

## 8. 微交互设计

### 8.1 按钮交互

#### 8.1.1 主要按钮
```
状态        视觉效果                         交互
─────────────────────────────────────────────────────
默认        蓝色背景 + 白色文字              无
悬停        亮度+5%                          鼠标指针
按下        缩放0.95 + 亮度-5%               触觉反馈
禁用        灰色背景 + 50%透明度             无响应
加载        Spinner + "处理中..."            禁用点击
```

#### 8.1.2 次要按钮
```
状态        视觉效果                         交互
─────────────────────────────────────────────────────
默认        透明背景 + 蓝色文字              无
悬停        10%透明度背景                    鼠标指针
按下        缩放0.95 + 20%透明度背景         触觉反馈
```

```
元素类型              标签                     提示
```

## 11. 性能优化

### 11.1 动画性能
- 使用GPU加速属性: transform, opacity
- 避免: width, height, margin等会触发重排的属性
- 复杂动画使用will-change提示浏览器优化

### 11.2 图片加载
- 缩略图先加载，高清图延迟加载
- 使用渐进式JPEG
- 支持WebP格式

### 11.3 列表优化
- 虚拟滚动: 超过30项使用
- 懒加载: 可见区域+2屏内容
- 图片懒加载: Intersection Observer
