# 视频精彩瞬间提取 - UI设计规范

## 文档信息
- **版本**: v1.0
- **创建日期**: 2025-12-05
- **适用平台**: iOS 15+
- **设计系统**: 基于iOS Human Interface Guidelines

---

## 1. 设计系统概览

### 1.1 设计理念
- **简洁优雅**: 去除不必要的装饰，专注内容本身
- **智能流畅**: AI驱动的无感体验，流畅的动画过渡
- **情感化设计**: 通过颜色、图标、动画传达愉悦感
- **系统化**: 统一的设计语言，可扩展的组件系统

### 1.2 设计价值观
1. **内容优先**: UI服务于内容，不喧宾夺主
2. **效率至上**: 减少操作步骤，提高创作效率
3. **反馈及时**: 每个操作都有即时反馈
4. **包容性**: 适配不同屏幕、不同用户群体

## 11. 暗色模式

### 11.1 颜色映射

```
亮色模式              →    暗色模式
────────────────────────────────────────
#FFFFFF (白色)        →    #000000 (黑色)
#000000 (黑色)        →    #FFFFFF (白色)
#F2F2F7 (浅灰)        →    #1C1C1E (深灰)
#E5E5EA (中灰)        →    #2C2C2E (中深灰)
#007AFF (系统蓝)      →    #0A84FF (亮蓝)
#34C759 (系统绿)      →    #32D74B (亮绿)
#FF3B30 (系统红)      →    #FF453A (亮红)
```

### 11.2 特殊处理

```
卡片背景:
  亮色: #FFFFFF
  暗色: #1C1C1E + 轻微边框 (rgba(255,255,255,0.1))

阴影:
  亮色: rgba(0, 0, 0, 0.08)
  暗色: rgba(0, 0, 0, 0.3) + 增强阴影强度

图片:
  亮色: 原图
  暗色: 降低5-10%亮度 (filter: brightness(0.9))

文字:
  保持良好对比度 (≥4.5:1)
```

## 13. 开发对接

### 13.1 设计标注
- 使用Figma自带标注功能
- 关键尺寸使用pt为单位
- 颜色使用HEX或rgba格式
- 字体大小使用px

### 13.2 切图规范
```
格式:
  - 图标: SVG (矢量) 或 PNG (位图)
  - 插图: PNG 或 WebP
  - 照片: JPEG 或 WebP

倍率:
  - @1x: 基准尺寸
  - @2x: 2倍尺寸 (视网膜屏)
  - @3x: 3倍尺寸 (高清屏)

命名:
  - icon_camera.svg
  - bg_gradient@2x.png
  - img_placeholder@3x.png
```
